# Chapter02: 개발 환경 구축

이번 챕터에서는 MSX1용 게임 제작을 위한 환경 구축을 한다. 현대에는 MSX1용 게임을 제작하지만 현대의 편의성을 가지고 C언어와 윈도우 10이상 운영체제에서 구현할 수 있도록 해준다.

아쉽게도 C++을 사용하여 개발은 어렵다고 한다. 하지만 C언어로도 충분히 가능하고 기존 어셈블리 코드에서 벗어나 좀 더 현대적인 코딩이 가능할 것 같다.

앞서 ubox MSX 라이브러리를 사용한다고 했던 이유도 C언어로 개발을 가능하게 해주기 때문이다. 따라서 makefile시스템을 사용하는 환경(POSIX 대응 빌드 시스템)을 위해 WSL2를 활용한다.

> C언어로 프로그램을 작성하면 성능이 낮은 구형 하드웨어에서 퍼포먼스가 떨어질 우려가 있다. 중첩 for문의 예가 그렇다. C언어로 구현한 게임 프로그램이 느려질 수 있는 이유는 C로 구현한 C함수로 호출하기 때문이다. ubox MSX 라이브러리는 이러한 문제를 해결하기 위해 어셈블리로 작성된 함수들을 제공한다. 따라서 C언어로 작성한 코드를 어셈블리로 작성된 함수로 호출하여 성능 저하를 막는다.

*즉, C언어로 인한 성능저하는 예상하듯 함수의 발생이 어셈블리의 중복과 한 단계를 더 거치기 때문이다. 따라서 ubox MSX 라이브러리의 어셈블리로 작성된 함수를 사용하여 성능저하를 막는다고 한다.*

IDE도 비쥬얼 스튜디오가 아닌 코드를 사용해주는 모습부터 너무 좋다. WLS2 때문이기도 하지만 개인적으로도 비쥬얼 스튜디오를 선호하지 않기에 만족스럽다.

*성공적으로 생성한 rom파일을 실행한 모습*

책에서 나오는대로 따라하면 무리없이 실행할 수 있다. 이런 분야의 책은 항상 따라할때 문제가 생기곤 했는데 저자가 워낙 잘 설명해주고 자료를 잘 정리해주어 한번의 막힘없이 성공했다.

책에서 말한대로 코드로된 것을 직접 make하여 빌드하고 해당 롬파일을 애뮬에 실행해보는 것 만으로 뭔가 성취감이 든다. 이 뒤로는 직접 작성한 코드대로 동작하는 게임을 만들어본다.
